# Тихолесье — HTML5 RPG prototype

Публичный эксперимент с механиками одиночной фэнтези-RPG для проверки интереса аудитории Playgama. **Это не многопользовательская игра.** Возможная MMORPG — отдельный будущий проект при положительной обратной связи.

## Запуск

Откройте `index.html` через локальный HTTP-сервер или GitHub Pages (используются ES-модули). Например: `python -m http.server 8000` и затем `http://localhost:8000`.

## Сейчас реализовано

- Карта 20 × 20, тайл 32 × 32, пиксельный Canvas без сглаживания.
- Перемещение по касанию с поиском пути по сетке.
- Дом 5 × 4 тайла, дверь строго на клетке, NPC, лесные существа и босс.
- Простой бой, опыт, уровни, трофеи, зелья, локальное сохранение.
- Управление с телефона; без серверов и сторонних SDK.

**Статус:** ранний технический прототип. Графика временная, противники неподвижны, баланс предварительный, нет магазина и монетизации. Для Playgama необходимо отдельно пройти интеграцию SDK, требования платформы и тестирование.

## Архитектура

`src/main.js` — запуск, `src/world.js` — временное игровое ядро, `style.css` — адаптивный интерфейс. Следующий этап — разделение на `scenes/`, `entities/`, `systems/`, `data/`, `assets/`. Дальше перенос на Phaser 3, когда утвердим визуальный масштаб и управление.

## Правило сетки

Размер тайла 32 × 32. Здания кратны тайлам. Дверь занимает один тайл, центр подхода и ось дорожки совпадают с центром дверной клетки. В будущем входы хранятся в метаданных карты, независимо от спрайтов.

## План

1. Проверить текущую сборку на телефоне и устранить проблемы управления.
2. Перейти на Phaser 3 и отделить сущности от систем.
3. Подготовить настоящий оригинальный тайлсет и спрайт-листы.
4. Ввести боевую систему, поведение мобов, предметы и экипировку.
5. Добавить босса с механиками, прогрессию, награды, баланс.
6. Интегрировать Playgama SDK и аналитику, подготовить описание и политику данных.
